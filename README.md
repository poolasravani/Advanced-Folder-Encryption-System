Advanced Folder Encryption System

A Python-based folder encryption and decryption system that uses AES encryption and provides a simple Tkinter graphical user interface.

📌 Project Description

The Advanced Folder Encryption System is designed to protect files and folders from unauthorized access. Users can select a folder, enter a password, and encrypt or decrypt the files using the application.

🎯 Objectives

- Secure folders using AES encryption.
- Provide a simple Tkinter GUI.
- Enable password-based encryption and decryption.
- Provide an easy-to-use interface for protecting files.

🛠️ Technologies Used

- Python 3.x
- Tkinter
- PyCryptodome
- AES Encryption
- Windows 10 / 11

⚙️ Installation

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/Advanced-Folder-Encryption-System.git

2. Open the project folder

cd Advanced-Folder-Encryption-System

3. Install required library

pip install -r requirements.txt

▶️ How to Run

Run the following command:

python main.py

Or, on Windows, double-click:

run.bat

🔐 How It Works

1. Run the application.
2. Browse and select the target folder.
3. Enter the password.
4. Click Encrypt Folder to encrypt the files.
5. To restore the files, select the folder again.
6. Enter the same password.
7. Click Decrypt Folder.

✨ Features

- AES-based file encryption.
- Password-based encryption and decryption.
- Simple graphical interface.
- Folder selection using Browse option.
- Encryption and decryption operations.
- Local system based file protection.

⚠️ Limitations

- There is no password recovery mechanism.
- The application works on the local system only.
- Users must remember their encryption password.
